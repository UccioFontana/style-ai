# STYLE-AI

STYLE-AI is a Flutter-based prototype for an AI-assisted music mix analysis application.

The app will allow producers and mixing engineers to upload a stereo mix, visualize technical audio metrics, compare the mix with reference tracks and receive an AI-generated technical report.

## Current Scope

The current version is focused on the Flutter frontend prototype.

Planned features include:

- audio upload flow;
- mix analysis dashboard;
- technical report visualization;
- loudness metrics;
- tonal balance charts;
- stereo and phase analysis;
- reference comparison;
- AI-generated mix feedback.
